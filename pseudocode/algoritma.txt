B. JUDUL PROGRAM

Program menghitung luas persegi panjang

C. DESKRIPSI MASALAH

Program ini di buat untuk menghitung luas persegi panjang berdasarkan nilai panjang dan lebar yang di masukkan olehpengguna

D. TUJUAN PROGRAM

Membantu pengguna menghitung luas persegi panjang secara cepat dan tepat.

E. ANALISIS INPUT, PROSES, DAN OUTPUT

1. INPUT:
  -Panjang persegi panjang (P)
-Lebar persegi panjang (1)

2. PROSES:
   -Menghitungluas persegi panjang.
   -Rumus:luas= panjang*lebar.

3. OUTPUT:
  -Menampilkan hasil luas persegi panjang.

F. ALGORITMA / PSEUDOCODE

#include <iostream>
using namespace std;

int main() {
  //DEKLARASI
  float panjang, lebar,luas;

  //input
  cout<<"masukkan nilai panjang :"<<endl;
  cin>>panjang;
  cout<<"nasukkan nilai lebar :"<<endl;
  cin>>lebar;

  //proses
  cout<<"hitung luas persegi panjang"<<endl;

  luas = panjang * lebar;

  //output
  cout<<"tampilkan hasil luas :" <<luas<<endl;

  return 0;
}


MULAI

   1. Deklarasikan variabel panjang, lebar dann luas.
   2. Masukkan nilai panjang.
   3. Masukkan nilai lebar.
   4. Hitung luas = panjang * lebar.
   5. Tampilkan nilai luas
